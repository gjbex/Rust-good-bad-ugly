# Units

This application illustrates how to use the `uom` crate to work with
quantities that carry physical units. Compared to plain `f64` values, it shows
how to:

* parse numerical command-line arguments with `clap`;
* convert raw command-line values into typed `uom` quantities;
* represent initial position as a `Length`;
* represent initial time and time step as `Time`;
* convert typed quantities back to canonical `f64` values for a simple
  numerical loop.

The example uses seconds for time values and meters for position values. This
keeps the command line simple while showing where unit-aware types enter and
leave the computation.


## What is it?

1. `src/main.rs` contains the main function of the application. It parses
   `x0`, `t0`, and `delta_t`, converts them into `uom` quantities, and runs a
   small time-stepping calculation.
1. `Cargo.toml` is the manifest file for Rust's package manager, Cargo. It
   specifies the dependencies on `clap` and `uom`.
1. `Cargo.lock` is automatically generated by Cargo to keep track of the exact
   versions of dependencies used in the project. It ensures that the same
   versions are used across different builds and environments.


## How to use?

Run the application with the following command to see the help message:

```bash
cargo run -- --help
```

Run a small example with initial position `1.0 m`, initial time `0.0 s`, and a
time step of `0.25 s`:

```bash
cargo run -- --x0 1.0 --t0 0.0 --delta-t 0.25
```
